# Security Reporting

For issues which do not pose a risk of remote exploitation, please report your findings as a [GitHub Issue](https://github.com/SpamTagger/SpamTagger/issues/new) and tag it with the `security` label.

For all other issues, you can privately and securely report them via email using this [GPG key](https://mer.tz/gpg/git.asc) (See [this guide](https://mer.tz/gpg) if you have no experience with GPG).
